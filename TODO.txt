■ 검증된 E2E 시나리오
--------------------------------------------------------------------
- "1년 정기예금 금리 높은 순 3개" → 실데이터 비교 + 공시월 + 유의문구
- "그중 두 번째 우대조건 자세히" → 멀티턴 참조 해소
- "급여이체 우대 있는 적금" → 벡터 검색으로 해당 조건 명시 상품 발굴
- 비로그인 신용대출 질의(비교·조건검색 모두) → 로그인 안내 / 로그인 후 → 조회 성공

--------------------------------------------------------------------
uv sync
cp .env.example .env   # OPENAI_API_KEY / FINLIFE_API_KEY / DATABASE_URL(Neon)
uv run python -m app.batch.sync_catalog   # 조건 검색 색인 (최초 1회+월 1회)
uv run uvicorn app.api.main:app --reload  # http://localhost:8000 (demo/demo1234!)
